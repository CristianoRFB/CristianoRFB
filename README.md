## Sobre mim

Sou **Desenvolvedor Full Stack** e estudante de **Análise e Desenvolvimento de Sistemas** na **Fatec Jales**.

- **React, Next.js e TypeScript**
- **Node.js, C# e .NET**

- **Git, GitHub, Docker e documentação técnica**
